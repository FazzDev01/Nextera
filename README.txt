MC Bubble - bubble CPS dan FPS untuk Minecraft

Cara build:
1) Android Studio: buka folder ini, lalu Build > Build APK(s).
2) Tanpa PC: upload folder ini ke repo GitHub, buka tab Actions,
   jalankan "Build APK", lalu unduh artifact MCBubble-apk.

Cara pakai:
Buka MC Bubble, izinkan "tampil di atas aplikasi lain", lalu Minecraft
terbuka otomatis dan bubble muncul. Ketuk bubble untuk panel, geser untuk memindahkan.
